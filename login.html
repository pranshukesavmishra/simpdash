Design notes
  • Google is the main option: one tap on phones where people are already signed in to Google.
  • The email field supports passkey autofill (autocomplete="webauthn"), so returning users can sign in without typing.
  • The reply is the same whether or not the email has an account, so nobody can use the form to check who is a customer.

Try it
  • Any 6 digits sign in. 111111 shows a wrong code; after 5 wrong tries the code locks for 15 minutes.
  • Pasting a whole code fills every box. Phones offer the code from Messages or Mail automatically.
  • On the server, the code is stored only as a keyed hash, used once, and limited per email and per network.
